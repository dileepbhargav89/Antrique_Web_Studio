# Form foundation

`form.tsx` — the standard RHF+Zod wrapper set (`Form`/`FormField`/
`FormItem`/`FormLabel`/`FormControl`/`FormDescription`/`FormMessage`/
`FormRequiredIndicator`), hand-authored (the shadcn CLI's own `form`
registry item doesn't produce files for this project's style/CLI-version
combination — see `docs/architecture/design-system.md` §3). No business
forms — usage pattern documented in design-system.md §4.
